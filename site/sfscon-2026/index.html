Install PA Webinar

PA Webinar runs on Kubernetes. Pick the guide that matches where you want to run it.

On your laptop

Minikube is the quickest way to try the whole platform on one machine: minikube guide.

The exact command for the workshop, with a fixed version, will be published here.

On-premises

A single server or a small cluster you manage: k3s guide.

In the cloud

  • Azure Kubernetes Service (AKS)
  • Amazon Elastic Kubernetes Service (EKS)
  • Google Kubernetes Engine (GKE)

All installation guides and checklists: docs/install.

Before you arrive

What to install and download before the workshop will be published here. The installation downloads several gigabytes, so plan to do it before you come.
