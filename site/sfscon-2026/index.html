The assistance room

A PA Webinar room where Raffaele, online, gives the instructions, shares the keys and answers technical problems. Daniele shows it on the projector in Crane Hall.

Join the assistance room

The room opens on Friday at 16:45. Before then the link shows a waiting room.

  1. Open the link, type your name and choose Enter now (if the room has just opened, the button reads The room is ready — come in). You do not need to register.
  2. Write in the Chat panel if something does not work: on the right on a laptop, at the bottom on a phone.
  3. Keep the tab open until the end. The questionnaire appears there when Raffaele closes the room.

Your task: create an event

How it works

  • Work on your own, without talking with the people next to you.
  • Find your way in the platform by yourself: Raffaele and Daniele help only with technical or access problems. Write those in the chat of the assistance room.
  • You are the administrator of a PA Webinar instance installed for the workshop. Raffaele shares the instance keys in the chat of the assistance room. Only the people in the room read that chat: the keys are never published on this page.
  • Other people use the same instance at the same time: your nickname in the title tells your event apart. The instances are deleted on Friday evening, with everything in them.

Pick the instance by the first letter of your first name, open its portal and choose Sign in with the instance key.

The scenario

Your organisation has to hold an institutional event online to present a new project to its stakeholders. Your job is to set up the event on PA Webinar: its information, the people involved and how others take part.

When you are done

Complete the creation of the event and reach its preview page. Check that the information you entered is correct and that the information to join the video call is there.

If something does not work

The key is refused

Copy it again from the chat, without spaces at the start or at the end. Each key works only on its own instance: check the first letter of your name.

“Too many requests in a short time”

Many people sign in from the same network at the same moment, and the instance accepts five attempts a minute from one network: wait a minute and try again, once.

The page does not load, or anything else

Write in the chat of the assistance room, with the name of your instance.

Install it yourself

PA Webinar runs on Kubernetes, and Docker Compose is enough to look at the portal. All the commands below use the same version as the workshop instances: commit d2162afd of the main branch, with the images tagged dev-f4021b1.

Always pass the tag

Without --tag, the scripts on main use the dev image, which changes with every push to the development branch and may not match the code you checked out.

  1. Docker Compose

    For development

    Look at the portal and the code on one computer, with demo events.

    You need
    Docker with Compose
    Measured
    about 1.4 GB, a minute and a half

    Development guide

  2. minikube

    Tested in labEvaluation, not events

    The whole platform on a Linux laptop, rooms included. Browsers join only from that laptop.

    You need
    4 CPUs, 8 GB of memory, 15 GB of disk
    Measured
    2.65 GB, 3 minutes 33 seconds

    minikube guide

  3. k3s

    Tested in labNo real event yet

    Small production on your own servers, with one command. No high availability.

    You need
    one server with 4 vCPUs and 8 GiB for about 20 people on camera, or three VMs

    k3s guide

  4. In the cloud

    AKS: runs real eventsEKS, GKE: not verified yet

    Production, with video bridges that scale to zero between events, a TURN relay and object storage.

    You need
    a managed Kubernetes cluster with a node pool for the bridges

From your laptopto production

Docker Compose, step by step

git clone https://github.com/italia/pa-webinar.git
cd pa-webinar
git checkout d2162afd
scripts/compose-up.sh --images registry --tag dev-f4021b1

At the end the script prints the addresses of the portal and of the test mailbox.

minikube, step by step

You need Linux, Docker, minikube 1.38.1 or later, Helm 3.16.3 or later, kubectl, openssl and curl. No credentials are needed.

git clone https://github.com/italia/pa-webinar.git
cd pa-webinar
git checkout d2162afd
scripts/minikube-up.sh --images registry --tag dev-f4021b1
  1. Open the conference address that the script prints (https://jitsi.<ip>.nip.io) once and accept its certificate, then do the same with the portal. Accepting only the portal is not enough: the room does not load.
  2. The instance key is in ~/.config/pa-webinar/minikube/pa-webinar/secrets.yaml, as ADMIN_API_KEY.
  3. Sign in at https://app.<ip>.nip.io/en/admin/login with Sign in with the instance key, then follow the same steps as in the workshop.
  4. The emails arrive in the mailbox at https://mail.<ip>.nip.io.

Recording and the post-production on GPU need images that are not public yet, so they stay off in this setup. macOS and Windows have not been tested.
